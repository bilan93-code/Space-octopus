# Motor CAD and analysis downloads

[Download the complete study and CAD ZIP (77 MiB)](https://github.com/bilan93-code/Space-octopus/raw/refs/heads/download/motor-cad-package-20261106/downloads/motor-study.zip)

[Download the smaller CAD ZIP (16 MiB)](https://github.com/bilan93-code/Space-octopus/raw/refs/heads/download/motor-cad-package-20261106/downloads/motor-cad.zip)

Extract either ZIP and begin with `Space-octopus/CAD_START_HERE.md`.

The complete ZIP includes reports, analysis source, configurations, dimensions,
winding diagrams, original reference PDFs, current active motor CAD, and the
earlier motor/gearbox concept. Installed runtimes and large raw solver caches
are omitted, with reproduction instructions included. The smaller ZIP contains
the current active CAD and winding exports, earlier concept CAD, current inputs
and both motor reports.

## CAD files

- [Current active motor STEP](https://github.com/bilan93-code/Space-octopus/raw/refs/heads/download/motor-cad-package-20261106/downloads/SpaceOctopusMotorActive.step)
- [Current active motor FreeCAD file](https://github.com/bilan93-code/Space-octopus/raw/refs/heads/download/motor-cad-package-20261106/downloads/SpaceOctopusMotorActive.FCStd)
- [CAD guide](CAD_START_HERE.md)

The current export contains 37 valid solids: stator iron, rotor iron, ten
magnets, 24 coil-side envelopes and a basic shaft. Housing, bearing seats,
retention and end turns still require detailed CAD design. The guide identifies
revision differences from the earlier complete concept assembly.

Both ZIPs have been checked for archive integrity and include SHA-256 file
checksums. [SHA256SUMS.txt](SHA256SUMS.txt) here verifies these downloads.
