# Motor dimensions and analysis

[Open or download the detailed motor report (PDF)](https://github.com/bilan93-code/Space-octopus/raw/refs/heads/download/motor-cad-package-20261106/downloads/Motor_Dimensions_and_Analysis.pdf)

This single 20-page PDF contains the motor dimensions, dimensioned sections,
exact stator-slot sketch points, magnet geometry, shaft datums, winding tables,
materials, masses, performance results, thermal and mechanical checks, and CAD
build order. No ZIP extraction is needed.

Current geometry: 96 mm stator outside diameter, 53 mm bore, 46 mm rotor-iron
OD, 52 mm bare magnet OD, 85 mm active stack and a basic 12 × 130 mm shaft.

Modeled dimensions and proposed surrounding-part envelopes are identified
separately. Endbells, finished bearing seats, end turns and coupling details
remain CAD choices; page 20 lists them.

Earlier ZIP packages remain in this branch as historical downloads. The PDF
above is the consolidated report requested for beginning CAD.
