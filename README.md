# Space Octopus ground prototype

[Open the interactive Three.js view](https://gltf-viewer.donmccurdy.com/#model=https%3A%2F%2Fraw.githubusercontent.com%2Fbilan93-code%2FSpace-octopus%2Fgh-pages%2Fground-prototype.glb)

Drag to orbit and scroll to zoom. The model includes the half-tooth ring gear rotations and revised end-cap screw holes for the 220 N·m ground-test target. A bench test is needed to establish the actuator rating.

The [ground prototype GLB](ground-prototype.glb) has the original colors and part hierarchy. The [standalone Three.js page](index.html) adds component isolation and an exploded view when opened in a browser. [Archived GitHub STL preview](Space-Octopus-actuator.stl)
